## Verification protocol established

For future source missions: preserve the supplied source file without copying it into the repository; create a page-aware section/method map; visually inspect any equation, table, or figure whose extracted text is ambiguous; add a test only when it checks a meaningful source-derived behavior; distinguish software tests from engineering checks and source validation; record non-matching methods as differences instead of changing solver results to imitate a different criterion. Equation references and manual example calculations belong in this ledger, not in physical input schemas.
